- A barra de status mostra FPS, ms do quadro, CPU e GPU.
- **F10** abre o **Debug Viewer**: o custo de cada sistema e de cada objeto. [Abrir](open:debug)
- **Janela > Stats** e **Ferramentas > Medir o Quadro (3 s)** dão números estáveis. [Medir agora](run:measure)
- Em **Configurações** (canto superior direito) mude a escalabilidade (Baixo, Médio, Alto, Épico).
- Se o editor parece travar ao importar ou assar: isso hoje roda em segundo plano; veja [Tarefas em segundo plano](article:background-tasks).
--- en
- The status bar shows FPS, frame ms, CPU and GPU.
- **F10** opens the **Debug Viewer**: the cost of each system and each object. [Open it](open:debug)
- **Window > Stats** and **Tools > Measure Frame Time (3 s)** give steady numbers. [Measure now](run:measure)
- In **Settings** (top right) change the scalability (Low, Medium, High, Epic).
- If the editor seems to freeze on an import or a bake: those run in the background now; see [Background tasks](article:background-tasks).
