--- pt
- **Ajuda > Referência da API** abre uma janela flutuante com todas as funções da engine, por categoria, com exemplo nas 4 linguagens. [Abrir](open:api) [Mostrar onde](show:Help>API Reference)
- No Editor de Código, **F1** abre a referência e **F12** num nome vai à página dele.
- Procure aqui também: o nome de uma função (ex.: `PlaySound2D`) aparece nas respostas.
--- en
- **Help > API Reference** opens a floating window with every engine function, by category, with an example in the 4 languages. [Open it](open:api) [Show me where](show:Help>API Reference)
- In the Code Editor, **F1** opens the reference and **F12** on a name goes to its page.
- Ask here too: a function's name (e.g. `PlaySound2D`) shows in the answers.
