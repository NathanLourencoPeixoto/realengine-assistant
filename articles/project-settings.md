- **Editar > Configurações do Projeto:** o jogo (nome, mapa inicial, Default Pawn), input (ações e teclas), física (gravidade), rendering (escalabilidade do jogo, Desempenho/Qualidade), áudio, online/Steam, plataformas. [Abrir](open:project)
- **Editar > Preferências do Editor:** idioma, escala da interface, mouse, câmera, autosave, limite de FPS, grade. [Abrir](open:prefs)
--- en
- **Edit > Project Settings:** the game (name, start map, Default Pawn), input (actions and keys), physics (gravity), rendering (the game's scalability, Performance/Quality), audio, online/Steam, platforms. [Open them](open:project)
- **Edit > Editor Preferences:** language, UI scale, mouse, camera, autosave, FPS limit, grid. [Open them](open:prefs)
