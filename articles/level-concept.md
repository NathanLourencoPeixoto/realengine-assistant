--- pt
- Um **nível** é um arquivo `.rlevel` com tudo que foi colocado no mundo (atores, luzes, terreno) e a luz assada dele.
- Um jogo pode ter vários: a fase 1, a 2, o menu. Troca-se com **Open Level** (ou Load Stream Level para carregar por partes).
- O nível que o jogo abre primeiro: Configurações do Projeto > **Game Default Map**. [Abrir](open:project)
--- en
- A **level** is an `.rlevel` file with everything placed in the world (actors, lights, landscape) and its baked light.
- A game can have several: level 1, level 2, the menu. Switch with **Open Level** (or Load Stream Level to load in parts).
- The level the game opens first: Project Settings > **Game Default Map**. [Open them](open:project)
