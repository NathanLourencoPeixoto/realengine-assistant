--- pt
Um **asset** é um arquivo do projeto que o jogo usa: malhas, materiais, texturas, sons, animações, Blueprints, scripts, níveis, widgets.
- Ficam na pasta **Content** e aparecem no Navegador de Conteúdo. [Gaveta de Conteúdo](article:content-drawer)
- Duplo clique abre o editor de cada tipo; arrastar coloca no nível.
- Renomear e mover pelo Navegador mantém as referências.
--- en
An **asset** is a project file the game uses: meshes, materials, textures, sounds, animations, Blueprints, scripts, levels, widgets.
- They live in the **Content** folder and show in the Content Browser. [Content Drawer](article:content-drawer)
- Double-click opens each type's editor; dragging places it in the level.
- Renaming and moving through the Browser keeps the references.
