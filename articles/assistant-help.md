--- pt
- Pergunte com suas palavras, em português, inglês ou espanhol; erros de digitação são tolerados.
- As respostas vêm dos **artigos** (baixados do GitHub na primeira pergunta, sem instalar nada), das **funções da engine** e da **descrição de cada controle**.
- **Baixar para usar offline** guarda os artigos no computador; **Atualizar** busca a versão nova.
- Os botões **Mostrar onde** destacam o controle na tela por alguns segundos.
- Não achou? **Enviar como sugestão** manda a pergunta para que o artigo seja escrito.
- **F1** abre o assistente (no Editor de Código, F1 é a referência da API).
--- en
- Ask in your own words, in Portuguese, English or Spanish; typos are fine.
- Answers come from the **articles** (fetched from GitHub on the first question, nothing installed), the **engine's functions** and **each control's description**.
- **Download for offline use** keeps the articles on the computer; **Update** fetches the new version.
- The **Show me where** buttons outline the control on the screen for a few seconds.
- Not found? **Send it as a suggestion** sends the question so the article gets written.
- **F1** opens the assistant (in the Code Editor, F1 is the API reference).
