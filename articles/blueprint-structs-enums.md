--- pt
- **Structure** (`.rstruct`): um pacote de campos (Nome, Dano, Ícone). Use Make / Break nos grafos.
- **Enum** (`.renum`): uma lista de opções (Parado, Andando, Correndo); **Switch on Enum** escolhe o caminho.
- **Data Asset**: valores prontos de uma Structure num arquivo (os itens do jogo), lidos por qualquer Blueprint.
- Scripts usam as Structures do projeto pelo nome e podem declarar as suas. [Structs no código](article:structs-guide)
--- en
- **Structure** (`.rstruct`): a bundle of fields (Name, Damage, Icon). Use Make / Break in graphs.
- **Enum** (`.renum`): a list of options (Idle, Walking, Running); **Switch on Enum** picks the path.
- **Data Asset**: ready values of a Structure in a file (the game's items), read by any Blueprint.
- Scripts use the project's Structures by name and can declare their own. [Structs in code](article:structs-guide)
