## Um projeto novo
1. Abra **Arquivo > Novo Projeto...** (ou o Project Browser, que aparece ao abrir o editor). [Mostrar onde](show:File>New Project...)
2. Escolha um modelo: **Terceira Pessoa**, **Primeira Pessoa**, **Visão de Cima** ou **Física**. Também há jogos de demonstração (RPG, Terror, Luta) para estudar.
3. Dê um nome e uma pasta e crie. O projeto abre com um nível pronto para jogar.

## Depois
- **Alt+P** joga no editor. Veja [Jogar no editor](article:play-in-editor).
- Os assets ficam na pasta **Content** do projeto. Veja [Gaveta de Conteúdo](article:content-drawer).

## A new project
1. Open **File > New Project...** (or the Project Browser that shows when the editor starts). [Show me where](show:File>New Project...)
2. Pick a template: **Third Person**, **First Person**, **Top Down** or **Physics**. There are demo games too (RPG, Horror, Fighting) to learn from.
3. Give it a name and a folder and create it. The project opens with a level ready to play.

## Next
- **Alt+P** plays in the editor. See [Play in the editor](article:play-in-editor).
- The assets live in the project's **Content** folder. See [Content Drawer](article:content-drawer).
