--- pt
O **Construction Script** roda quando o ator é colocado, movido ou mudado no editor (e quando é criado no jogo), antes do BeginPlay.
- Use para montar coisas a partir dos valores do Details: uma cerca com N postes, a cor por variável.
- No editor ele só mexe no próprio ator.
--- en
The **Construction Script** runs when the actor is placed, moved or changed in the editor (and when it's made in the game), before BeginPlay.
- Use it to build from Details' values: a fence with N posts, the color from a variable.
- In the editor it only touches its own actor.
