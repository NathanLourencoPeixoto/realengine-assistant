# Real Engine — base do Assistente / Assistant knowledge base

**PT** — Os artigos que o Assistente da Real Engine (Ajuda > Assistente, F1) busca. Não há IA: a busca roda no próprio
editor. O editor lê o `index.json` daqui (online) ou guarda uma cópia para usar offline ("Baixar para usar offline").

**EN** — The articles the Real Engine's Assistant (Help > Assistant, F1) searches. No AI: the search runs inside the
editor. The editor reads `index.json` from here (online) or keeps a copy to use offline ("Download to use offline").

| Arquivo / File | |
|---|---|
| `index.json` | a base empacotada que o editor lê / the packed base the editor reads |
| `manifest.ini` | versão e tamanho / version and size |
| `articles/*.md` | os artigos (pt e en) / the articles (pt and en) |
| `synonyms.txt` | grupos de sinônimos / synonym groups |
| `coverage.txt` | cada área da engine e seus artigos / each engine area and its articles |

Gerado por `tools/assistant_pack.py` no repositório da engine. / Generated by `tools/assistant_pack.py` in the engine's
repository.
